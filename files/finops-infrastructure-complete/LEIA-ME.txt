## 🚀 INÍCIO RÁPIDO (3 passos)

### 1️⃣ Extrair o ZIP
```bash
unzip finops-infrastructure-complete.zip
cd bicep
```

### 2️⃣ Editar configuração
```bash
# Abrir: bicep/parameters.dev.json
# Alterar:
#   - customerPrefix: "seu-nome" (3-10 caracteres)
#   - contactEmail: "seu@email.com"
#   - sqlAdminPassword: "SenhaForte123!@#"
```

### 3️⃣ Executar deployment
```powershell
# No diretório bicep/
az login
az account set --subscription "SUA_SUBSCRIPTION_ID"
./deploy.ps1 -SubscriptionId "SUA_SUBSCRIPTION_ID"
```

## 🎯 O QUE SERÁ CRIADO

Após executar `deploy.ps1`, você terá no Azure:

- ✅ SQL Server + Database (2GB, 23 tabelas)
- ✅ 2x Container Apps (API + Worker)
- ✅ Storage Account (reports, exports, backups)
- ✅ Service Bus (filas de análise)
- ✅ Container Registry (imagens Docker)
- ✅ Key Vault (secrets)
- ✅ Managed Identity (permissões)
- ✅ Log Analytics + App Insights

**Custo:** ~$68-143/mês (ambiente dev)

## 🗄️ APÓS O DEPLOYMENT: Inicializar Database

```powershell
# Opção 1: Azure Portal
# SQL Server → Query Editor → Execute: database/schema.sql

# Opção 2: Azure CLI
az sql db query \
  --server sql-finops-teste-xyz123 \
  --database finopsdb \
  --admin-user finopsadmin \
  --admin-password "SuaSenha" \
  --input ../database/schema.sql
```
